## 4. Preprocessing Configuration

| Setting | Value |
|---------|-------|
| Feature channels | Voltage, Current, Temperature (raw time-series within each cycle) |
| Features extracted | 20 per-cycle statistical features |
| Capacity | Excluded from predictive features (used only for SOH target) |
| Cycle index | Excluded from predictive features |
| Feature scaler | MinMaxScaler, fitted on base partition only |
| Target scaler | MinMaxScaler, fitted on base partition only |
| XGBoost lag depth | 5 preceding cycles (causal, no future leakage) |

---

## 5. Sequence Construction

| Setting | Value |
|---------|-------|
| Sequence length (SEQ_LEN) | 32 consecutive discharge cycles |
| Window type | Overlapping sliding window |
| Cross-battery sequences | NEVER — sequences built within each cell independently |
| LSTM/GRU input shape | (32, 20) |
| XGBoost input shape | (20 × 6,) = (120,) lag matrix |

## 6. Within-Battery Split Strategy (chronological)

| Partition | Fraction | Purpose |
|-----------|----------|---------|
| Base training | 60% | Train GRU, LSTM, XGBoost base models |
| Early-val | 10% | EarlyStopping validation (never used for metrics) |
| Meta block | 15% | Train ElasticNet meta-learner |
| **Test set** | **15%** | **Final evaluation (untouched until end)** |

---

## 7. LOO Split Strategy (training batteries)

| Partition | Fraction | Purpose |
|-----------|----------|---------|
| Base training | 70% | Train GRU, LSTM, XGBoost |
| Early-val | 15% | EarlyStopping validation |
| Meta block | 15% | Train ElasticNet meta-learner |
| **Held-out battery** | **100%** | **External test — completely unseen during all training** |

---

## 8. Model Architecture

### GRU
```
Input(32, 20) → GRU(64, return_sequences=True) → Dropout(0.20) →
GRU(64) → Dropout(0.20) → Dense(1)
Optimizer: Adam(lr=0.001), Loss: MSE
EarlyStopping: monitor=val_loss, patience=15 (within-battery) / 8 (LOO)
```

### LSTM
```
Input(32, 20) → LSTM(64, return_sequences=True) → Dropout(0.20) →
LSTM(64) → Dropout(0.20) → Dense(1)
Optimizer: Adam(lr=0.001), Loss: MSE
EarlyStopping: same as GRU
```

### XGBoost
```
n_estimators=300, max_depth=4, learning_rate=0.05,
subsample=0.8, colsample_bytree=0.8
Input: lag-augmented feature matrix (120 features)
```

### ElasticNet Meta-Learner
```
alpha=0.05, l1_ratio=0.5, max_iter=5000
Input: [XGB_prediction, GRU_prediction, LSTM_prediction] on meta block
```

## 9. Evaluation Protocol

- All metrics computed on the **final test set only**
- Test set never used for: training, early-stopping, model selection, meta-learner tuning, ensemble weight selection
- Results reported as **mean ± std** across 3 independent random seeds
- Within-battery and LOO results generated by separate scripts

## 13. Generalization Conclusion

The model demonstrates **partial cross-battery generalization** (LOO R² = 0.79 for Stack EN).
The Weighted Ensemble achieves better LOO generalization (R² = 0.87, RMSE = 2.69) than the
learned ElasticNet stack (RMSE = 3.04), indicating that the meta-learner's learned fusion
weights do not transfer robustly across battery identities. For deployment on unseen batteries,
the Weighted Ensemble is the recommended inference-time configuration.
